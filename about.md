# FreeCollab

Edit a Geometry Dash level together with friends, in real time.

## How to use
1. Open a level in the editor and pause.
2. Press **Collab** (bottom right).
3. Type a room code and press **Join**. Everyone who joins the same room edits the same level.
4. Press **Leave** when you're done.

Use a long, unique room code. Anyone who knows it can join.

## Rooms and levels
A room belongs to one level. The first person to join claims the room for the level they have open, identified by its name.

If you join a room from a different level, FreeCollab saves your current level, then opens a level with the room's level name (creating it if you don't have one yet) and loads the host's objects into it. Your own level is never changed.

## Things to know
- Changes sync about once a second, not instantly.
- If two people edit the same object at the same time, the last change wins.
- Changes from other players never touch an object you currently have selected. They wait until you deselect it.
- Two different levels with the same name count as the same level.
- You need an internet connection.
- The mod rejoins your last room automatically when you open that room's level.

## Privacy
FreeCollab sends your level's object data, your level's name, your room code, and a random client id to an online server run by the mod's developer so other people in the room can see your edits. Rooms are not private or password protected. Don't use it on levels you want to keep secret.
